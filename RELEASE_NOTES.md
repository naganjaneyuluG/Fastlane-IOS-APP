This release focuses on enhancing the development and deployment process for the application, with updates to the build and deployment workflows, as well as improvements to the codebase. It also includes several key improvements to the user interface, ensuring a better experience for users.

* The CI/CD pipeline has been updated with changes to the `ci-notes.yml` file, streamlining the testing and deployment process for the application.
* Updates to the `android-deploy.yaml` file and the Fastfile have improved the automation of the Android deployment process, making it more efficient and reliable.
* The application now uses Java 17 in its GitHub action, ensuring compatibility with the latest Java features and security updates.
* The rexml library has been bumped from 3.2.8 to 3.3.9 in the ios directory, improving the parsing and processing of XML data in the application.
* The Facebook logo in the About page has been downscaled, improving the overall aesthetic and user experience of the page.
* The Shorebird setup and Code signing setup have been added, enhancing the security and authenticity of the application.
* The version name is now displayed in the About Us section, providing users with clear information about the application's version and updates.
* The build and deployment process for both Android and iOS has been improved, with updates to the `android-deploy.yaml` file, the Fastfile, and the use of Fastlane for automation.
